# TikTok Image Booster MVP

iPhoneのSafariで使う前提の試作版です。

## 現在できること
- 写真を1枚選択
- 2倍 / 4倍を選択
- TikTok用 1080×1920（9:16）に中央トリミング
- 高品質なブラウザ内リサイズ
- JPGとして保存

## 注意
このMVPは「AIアップスケール」そのものではなく、端末内の高品質リサイズ版です。
次の段階でReal-ESRGAN等のAIモデルを組み込みます。

## iPhoneで試す方法
このフォルダをHTTPSで公開するとSafariから利用できます。
GitHub Pages / Cloudflare Pages / Netlify等で公開できます。
